# 트릭컬 스킬 가이드

모바일 게임 **트릭컬 리바이브**의 사도별 스킬·어사이드 정보와 강화 레벨 추천을 모아 둔
팬 사이트입니다. 디시인사이드 트릭컬 갤러리에서 유지·배포 중입니다.

**▶ https://mediate1082.github.io/Trickal-Revive-Skill-Guide-Beta-0.8/**

## 무엇을 볼 수 있나

| 페이지 | 하는 일 |
|---|---|
| **스킬 가이드** (`index.html`) | 사도 135명의 저/고학년 스킬·일반공격·어사이드, 성격·역할·배치 필터, 부가 효과 검색 |
| **사도 추천** (`recommend.html`) | 리세마라·뉴비 선택권·콘텐츠별 추천. 줘팸터·심해 대격돌·차원 대충돌 2.0 은 **편성판과 아티팩트 배분**까지 |
| **티어 메이커** (`tiermaker.html`) | 직접 티어표를 짜서 PNG 로 저장 |

## 어떻게 만들어졌나

**백엔드가 없습니다.** 순수 HTML + CSS + JavaScript 이고, 모든 데이터는 `data/` 의 CSV 를
브라우저가 직접 읽어 그립니다 (PapaParse). GitHub Pages 가 파일을 내려줄 뿐입니다.

```
index.html · recommend.html · tiermaker.html   페이지 셋
main.js · ui.js · recommend.js · tiermaker.js  각 페이지 로직 (ui.js 는 공유)
style.css · tooltip.js · theme.js              셋이 같이 쓰는 것
version.js                                     캐시 버스팅 버전 (유일한 출처)
data/*.csv                                     사도·스킬·버프·추천 데이터
assets/                                        아이콘 · 초상화 · 폰트
```

### 로컬에서 보기

`fetch` 로 CSV 를 읽으므로 **파일을 직접 열면(`file://`) 안 됩니다.** 간단한 정적 서버면
충분합니다.

```bash
python -m http.server 8765
# http://localhost:8765
```

## 데이터에 대하여

- 스킬 수치·설명은 **인게임 텍스트를 그대로** 옮긴 것입니다
- 추천 등급과 편성은 **사람이 판단해 적은 것**이라 메타에 따라 바뀝니다.
  일부 분류는 디시 갤러리 공략을 참고했고 본문에 출처를 링크해 두었습니다
- 끝난 이벤트·지난 시즌은 지우지 않고 **"지난 것" 으로 표시**합니다.
  당장 쓸 수는 없어도 육성 방향을 고르는 데는 참고가 되기 때문입니다
